# Projeto_Heineken_vendas

Para ser realizado o projeto de vendas, antes de tudo é necessário seguir alguns passos para que se obtenha sucesso na entrega final que são:
1 – Organizar os recursos, cálculos, dados e extras (dessa forma, o projeto fica organizado)
2 – Necessário entender os dados antes de sair modelando gráficos.
3 – No excel, para fazer análise dos dados é necessário usar a tabela dinâmica.
4 – Após escolher a tabela dinâmica, faz-se necessário escolher os campos que serão analisados.
5 – Após a escolha dos campos, ir na guia inserir e escolher os gráficos adequados para cada conjunto de dados.
6 – Realizar os cálculos que serão utilizados com os gráficos.
7 – Ao escolher os gráficos, é preciso legendar cada situação, os gráficos precisam falar por si só.
8 – Escolher as cores adequadas para os gráficos.
9 – Realizar o alinhamento dos gráficos escolhidos
10 – Realizar a segmentação de dados e linkar tudo através da Conexão de relatório.
